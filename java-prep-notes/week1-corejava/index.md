## Learning Goals

After completing Week 1-2, you should be able to:

- Explain the difference between primitives and wrappers
- Apply all 4 OOP principles with examples
- Choose the right Collection for any use case
- Explain HashMap internals (interview favorite!)
- Handle exceptions properly
- Write basic multithreaded code
