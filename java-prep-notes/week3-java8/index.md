## Learning Goals

After completing Week 3, you should be able to:

- Write concise lambda expressions and method references
- Use the built-in functional interfaces (Function, Predicate, Consumer, Supplier)
- Build, transform and collect data with the Stream API
- Use advanced collectors, grouping, partitioning and parallel streams
- Avoid `NullPointerException` with `Optional`
- Work confidently with the `java.time` API
